# Hackatones

Prepararse para las hackatones de producto, de datos abiertos y de IA: leer el reto, elegir una idea que se pueda demostrar, construir un prototipo en 24 o 48 horas con las herramientas adecuadas, y presentar ante un jurado que puntúa con una rúbrica.

**Ver en línea:** https://aaramirez.github.io/hackatones/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
